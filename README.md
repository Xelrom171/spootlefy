# 🎵 Spootlefy

A lightweight, web-based music streaming interface powered by the YouTube Data API. **Spootlefy** allows users to search for tracks, view results, and stream audio directly in their browser with a clean, dark-mode UI.

## ✨ Features

*   **Global Music Search:** Instantly find songs or artists using the YouTube Data API.
*   **Minimalist Player:** A streamlined interface focusing on the music, with Play/Pause functionality.
*   **Mobile Optimized:** Fully responsive design that works great on iPhones and Android devices.
*   **iOS Support:** Includes specific fixes for YouTube autoplay and audio unmuting on mobile browsers.
*   **Dark Mode:** A sleek, "Spotify-inspired" aesthetic for comfortable night-time listening.
